## Publication status

Public source/download distribution is separate from OpenAI's plugin directory. These packages have not been submitted, approved or published in that directory by this workflow. Existing private account releases are preserved. Publisher verification, platform checks and owner attestations remain separate requirements.

Both are skills-only packages, with no connected publisher backend, paid checkout, wallet, automatic scheduling or financial authority. Availability is intended for all countries supported by the relevant host and applicable rules; no region eligibility is guaranteed.
