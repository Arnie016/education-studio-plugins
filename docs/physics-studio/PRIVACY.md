# Physics Studio privacy notice

Publisher: **Arnav Salkade**. Effective 20 October 2026. This notice covers this skills-only package, not the independent services of the application in which you use it.

## During use

This package has no publisher-operated server, database, analytics endpoint, embedded payment service or telemetry collector. Installing or using it does not by itself send your conversations to Arnav Salkade. Your host application and its chosen model/tool providers process your prompts, files, outputs and account information under their own policies and controls. Review those policies before use.

Host-provided browsing, code execution or other tools can have their own data flows. Review and approve those actions in your host. Do not provide private student records, identifying information about other people, credentials, confidential school documents or material you lack permission to share. Code and calculations run only where your host supports them; no independent cloud workspace is supplied by this package.

## Website, downloads and support

GitHub hosts this repository, downloads and public issues under [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Its ordinary account and hosting data practices are separate from the plugin. External reference links follow their providers' policies.

If you open a Physics Studio support issue, your GitHub identity and issue contents are public and visible to Arnav and other readers. Use non-sensitive examples. Manage your account and content using GitHub's controls; ask through the issue tracker about moderation or removal of material in this repository. Do not publish private data in a deletion request.

No student data, document passwords, payment details or learning records are written on-chain by this package. No student data is sold or collected by a publisher backend as part of the plugin's current design. This statement does not describe third-party model providers' practices.

## Audience and updates

Intended for users aged 13 and above, with any additional host, local and school requirements applying. Not designed to collect information from children under 13. Future changes involving a backend, accounts, payments or analytics require an updated notice before those data flows are introduced.
