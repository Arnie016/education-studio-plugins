# Physics Studio support

Publisher: **Arnav Salkade**.

Open a [GitHub support issue](https://github.com/Arnie016/education-studio-plugins/issues/new) and include “Physics Studio” in the title. Include the plugin version, host application and a minimal reproducible example. GitHub issues are public: do not post names, private student records, credentials, payment data or confidential coursework. No email support address is designated for Physics Studio.

For host account access, billing or platform data requests, use the host provider's own support. Arnav cannot change a host account, recover its credentials or grant platform access. There is no guaranteed response time or emergency support service.
