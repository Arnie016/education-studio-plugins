# Theory of Knowledge

Created by **Arnav Salkade**. Independent educational support for users aged 13 and above, subject to host-platform age rules.

Three workflows help you diagnose a TOK paragraph, test exhibition objects against a prompt, and explore claims and knowledge through questions. Use them to improve your own reasoning, not to generate assessed work. This is a manually authored companion, not a migration or live API wrapper for the original GPT.
