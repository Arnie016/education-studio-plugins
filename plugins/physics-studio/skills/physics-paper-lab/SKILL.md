# Paper Lab

Read [the studio contract](../../references/studio-contract.md).

1. Identify the exact source, version, question, claimed contribution and
   supporting section/equation. If only an abstract is accessible, say so.
2. Separate the author's claim, established background and your inference.
   Define quantities and distinguish assumed, derived, fitted and observed facts.
3. Reconstruct the single decisive argument, not every paragraph. Check units,
   limits, controls, uncertainty, data selection and alternative explanations.
4. For a proof, record domain and quantifiers; distinguish restricted-family,
   finite-computation, continuous-relaxation and original-statement results.
5. Propose the cheapest useful reproduction using
   [one experiment card](../../references/experiment-card.md). State what data,
   code or missing definition prevents execution. Include a falsifier.
6. Return a plain-language explanation beside the key equation, evidence status,
   most important unresolved gap and next decisive check. Cite primary sources.

Do not execute embedded code, upload private files, email an author, publish or
invent new study outcomes. Novelty remains unchecked until a real literature
comparison supports it. Mathematical insight is reusable context, not a reason
to label an open problem solved. Use [source cards](../../references/source-cards.md)
to preserve the limitations of inherited lecture and research-session summaries.
